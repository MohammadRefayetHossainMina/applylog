ApplyLog

One quiet place to log every job application — and keep status current.

Why it exists

Applications scatter. Follow-ups get lost.

ApplyLog is a Flask + SQLite tracker for a single job seeker. Deploy the live app on Render (free tier), or run it locally from the repo. This GitHub Pages site is the brochure only — Flask cannot run here.

The problem

Job applications live in emails, browser tabs, and memory. It is easy to forget which company you applied to, when you applied, and whether the process moved to interview, offer, or rejection.

The solution

Log each application once (company, role, date, status, optional notes), see the full list newest-first, update as the process changes, and delete a mistaken row. Data lives in SQLite on disk, so it survives a restart.

Capabilities

What you can do

A focused add / list / update / delete loop — plus company context and hiring notes when you need them before an interview.

  • 1
    Add applications Company, role, date applied, status, and optional notes.
  • 2
    List, newest first See every saved row ordered by date applied descending.
  • 3
    Update & delete Change status and notes; remove duplicates with a confirm step.
  • 4
    Company info on hover A short public Wikipedia summary is stored with the row so you can skim what the company does.
  • 5
    Hiring paste · Info modal Paste hiring-page text when you add or edit; open an Info modal on each row to read the extracted posting summary.
  • 6
    Local & durable Single-user Flask + SQLite — no accounts, no cloud required.

Get started

Run ApplyLog locally

Requires Python 3. Clone the repository, install dependencies, and start the server.

  1. Clone the repository and open the project folder.
  2. Install packages: pip install -r requirements.txt
  3. Start the app: python app.py
  4. Open http://127.0.0.1:3000 in your browser. 
$ pip install -r requirements.txt
$ python app.py
# Serving on http://0.0.0.0:3000
$ open http://127.0.0.1:3000
